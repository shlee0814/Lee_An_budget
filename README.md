# 하루 가계부 — GitHub Pages

정적 파일로 실행되는 개인 가계부입니다. 내역, 고정 지출, 목표 및 분류 기억은 현재 브라우저의 저장 공간에 보관됩니다. 기기나 브라우저 간 자동 동기화 및 공동 사용은 지원하지 않습니다. 브라우저 데이터를 삭제하면 기록이 사라질 수 있으므로 전체 백업 버튼으로 JSON을 정기적으로 저장하세요. 백업 가져오기는 현재 기록을 교체합니다. 기존 Sites 공동 장부에서 내려받은 JSON 백업도 가져올 수 있습니다.

## 배포

이 폴더의 파일을 GitHub 저장소의 기본 브랜치 루트에 올린 후, 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch, 기본 브랜치와 `/ (root)`를 선택합니다. 빌드 과정은 필요하지 않습니다. 공개 저장소와 공개 Pages 사이트에는 개인 가계부 백업이나 데이터베이스를 올리지 마세요.

로컬 확인은 이 폴더에서 `python -m http.server 8000` 실행 후 `http://localhost:8000/`에 접속하세요. 사진 인식은 브라우저에서 실행되며 최초 모델 로딩에 시간이 걸릴 수 있습니다.
